按空白鍵或點畫面播放影片（約 2 分鐘）。影片裡都是實際操作畫面。

免費外掛，放在 GitHub 公開下載；大部分功能不需要 AI，也不需要付費服務。

這是 ZotMax 的定位：它做整理、追蹤、計數這些雜事，不替你判斷、不替你寫。新安裝預設是「研究生引導」模式，會自動找文獻和寫草稿的功能都先關著。
沒用過也沒關係

三個軟體，各用一句話認識

Zotero

收文獻的書櫃

存書目和 PDF、畫重點、產生引用格式。一定要裝（Zotero 10）。

Obsidian

自己電腦裡的筆記本

筆記是一般文字檔，存在自己電腦；建議 1.14 以上，可以看彩色劃線和看板。

Notion

線上的資料庫

每篇一頁，手機也能看；設定精靈可以幫你建好資料庫。

Obsidian、Notion 至少選一個，兩個都要也可以

很多老師沒用過 Obsidian 和 Notion。可以這樣比喻：Zotero 是書櫃，Obsidian 是放在自己電腦的筆記本，Notion 是放在網路上的資料庫。只想要一個就選一個，不用兩個都學。在意資料放在自己電腦的，選 Obsidian；想要在手機看、跟同學分享的，選 Notion。
01
安裝INSTALL

① 到 GitHub 下載 .xpi

Releases 頁面的 zotero-bridge-版本號.xpi（舊名，同一個外掛）

② Zotero → 工具 → 附加元件

打開外掛管理員

③ 齒輪 → Install Plugin From File

選剛剛下載的 .xpi，裝好後設定精靈會自動跳出來

檔名還是舊名 zotero-bridge，是同一個外掛，不用擔心。官網 bobyu89.github.io/ZotMax 有「下載最新版 .xpi」按鈕和一步一步的安裝精靈。
02
設定精靈SETUP WIZARD

新手選「研究生引導」

自動找文獻、AI 草稿先關著；整理、評讀、搜尋照常能用

選筆記放哪裡

Obsidian：選筆記庫資料夾
Notion：精靈會帶你接上資料庫

AI 可以先跳過

每個功能之後都能在設定裡單獨開關

設定精靈共六步：歡迎、選模式、筆記放哪、AI（選用）、同步一次、完成。按 Esc 可以隨時關掉，設定會留著。「進階」模式會打開 AI 草稿、批次 API 和自動追蹤新文獻，熟悉之後再開。
03
同步SYNC

① 選幾篇文獻

第一次先選 3～5 篇試試

② 按工具列的 ZotMax 按鈕

選「同步到 Notion + Obsidian」

不想花 AI 費用

選「同步但不呼叫 AI」

選單依用途分成同步、整理、找文獻、篩選與評讀、AI 輔助與寫作。右邊是 Zotero 右側面板的 ZotMax 區塊：重點摘要、在 Obsidian／Notion 開啟的連結，以及常用按鈕。記不得功能在哪，按 Ctrl+Shift+P 打開快速指令，輸入關鍵字就找得到。
同步之後 · Obsidian

每篇文獻一份筆記

研究設計、證據等級、PICO

寫在屬性欄，可以排序、篩選、做成看板

最上方是重點摘要

劃線、評讀表、AI 筆記收在下面，點開才展開

劃線點得回 PDF 原位置

引用前回原文核對很方便

重新同步不會蓋掉你寫的內容

ZotMax 只更新它自己產生的區塊

左上是筆記的屬性欄，研究設計、證據等級、JBI 等級、PICO 都在這裡。左下是重點摘要。筆記裡標著「此區塊由 ZotMax 自動產生」的範圍以外，都是你自己的空間，重新同步不會覆蓋。示範的是 Osman 等人 2026 年的系統性回顧。
同步之後 · Notion 與閱讀狀態

每篇一頁，閱讀進度三邊一致

Notion 欄位自動建立

APA、摘要、評讀結果、評讀工具

四種閱讀狀態

待讀、閱讀中、已讀、已引用

改一邊，三邊跟著改

Obsidian 另有閱讀進度看板，拖曳卡片就能改

畫面是 Notion 資料庫；Obsidian 那邊另有一個閱讀進度看板（影片裡有出現）。在任何一邊改閱讀狀態，下次同步時另外兩邊會跟著更新。請不要改 Notion 裡的英文欄位名稱，外掛靠這些名稱對應資料。
寫回顧論文時

它還能幫你做這些

篩選 · PRISMA

標題摘要、全文篩選存成標籤，產生 PRISMA 2020 流程圖

CASP · JBI 評讀

逐題記下答案與根據，雙人評讀可算 Cohen's κ

概念串成網

概念卡片把多篇文獻連起來，在 Obsidian 看關聯圖

進度報告

整理閱讀與篩選進度給指導教授，不需要 AI

另有：醫學資料庫搜尋與 PICO 檢索式、PubMed 新文獻追蹤、引文追蹤（OpenAlex）、文獻比較表。

做系統性回顧、範圍回顧、EBHC 報告或論文第二章時特別有用。要提醒：外掛只負責記錄和計數，納入、排除的決定還是由你自己判斷。
AI 是選用的

要用 AI，先知道這三件事

自備 API 金鑰

Claude 或 OpenAI，依用量付費；Claude Pro、ChatGPT Plus 訂閱不能用

大量產生先估費用

批次 API 約半價、最久等 24 小時；大量作業前會請你確認

產出都是初稿

數字和引用一定回原文核對

API 金鑰存在 Zotero 的密碼管理員，不會寫進設定檔。AI 筆記會寫研究設計、樣本、PICO、證據等級和評讀初稿，但都標示為初稿；評讀表上會寫「AI 初評，尚未核對」，核對完要自己勾選「我已核對」。

老師最常問

Q&A

要付費嗎？

外掛免費，大部分功能不用 AI。AI 功能用自己的 API 帳號另外計費。

只用 Obsidian 或只用 Notion 可以嗎？

可以，至少接一個就能用；兩個都接也可以。

文獻會被送給 AI 嗎？

只有開啟 AI 功能並設定金鑰時才會送；自動同步不呼叫 AI。病人資料不要放進 AI 筆記。

中文文獻可以嗎？

有中文 APA 7 專用格式，也能檢查並修正匯入資料的常見錯誤，改錯可以復原。

其他常見問題：Zotero 11 推出時外掛可能暫時停用，確認相容後會恢復；OpenAlex 對中文期刊和較舊文獻的資料可能不完整。有問題可以用外掛裡的「回報問題」，或到 GitHub 開 Issue。
