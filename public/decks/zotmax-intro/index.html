免費外掛；大部分功能不需要 AI。新安裝預設「研究生引導」模式，找文獻和寫草稿的功能先關著。

它做整理、追蹤、計數這些雜事，不替你判斷、不替你寫。這也是它和「AI 幫你寫回顧」類工具最大的不同。
沒用過也沒關係

三個軟體，各用一句話認識

Zotero

收文獻的書櫃

存書目和 PDF、畫重點、產生引用格式。一定要裝（Zotero 10）。

Obsidian

自己電腦裡的筆記本

首頁、看板、星球地圖這些新功能都在這裡；建議 1.14 以上。

Notion

線上的資料庫

每篇一頁，手機也能看；設定精靈可以幫你建好資料庫。

Obsidian、Notion 至少選一個；拿不定主意先選 Obsidian

比喻：Zotero 是書櫃，Obsidian 是放在自己電腦的筆記本，Notion 是放在網路上的資料庫。在意資料留在自己電腦、想用星球地圖的選 Obsidian；想在手機看、和同學分享的選 Notion。
01
安裝INSTALL

① 到 GitHub 下載 .xpi

Releases 頁面的 zotero-bridge-0.39.0.xpi（舊名，同一個外掛）

② Zotero → 工具 → 附加元件

右上角齒輪 → Install Plugin From File…

③ 只要裝一次

之後 Zotero 會自動更新 ZotMax；裝好設定精靈會自己跳出來

用 Firefox 下載時，要在連結上按右鍵「另存連結」，不然 Firefox 會把 .xpi 當成自己的擴充功能。完整步驟和截圖都在「ZotMax 完整安裝指南」那一頁。
02
設定精靈SETUP WIZARD · 約 3 分鐘

新手選「研究生引導」

找文獻、AI 草稿先關著；整理、評讀、搜尋照常能用

筆記放哪裡

Obsidian：按「選擇資料夾」選 vault
Notion：貼 token，精靈可以幫你建資料庫

按「略過」什麼都不改

Esc 關掉，存過的設定都會留著；快速指令搜「設定精靈」可以重跑

精靈共六步：歡迎、選模式、筆記放哪、AI（選填）、試一次、完成。「試一次」會用一篇文獻同步，不呼叫 AI、不花錢。Notion 要先建 integration、把頁面分享給它，指南第 2 步有逐步說明。
AI 是選用的

AI 要選哪一個？四種都可以

沒有 API key → 網頁版 AI

把提示詞貼到 ChatGPT、Claude、Gemini 網頁，再貼回來。不用另外付費

想自動又不想花錢 → OpenRouter

Google 帳號註冊、免信用卡，沒儲值時每天約 50 篇

要穩定、量大 → Claude／OpenAI API key

依用量計費；超過 5 篇會先確認費用

先不用

同步、評讀、PRISMA、儀表板都不需要 AI

最常被問：「我有 ChatGPT Plus／Claude Pro 可以用嗎？」訂閱不能當 API key，但可以用網頁版 AI，筆記一樣完整。之後可以在 設定 → ZotMax → AI 改。
新功能 · 免 API key

網頁版 AI：複製、貼上、存回來

① 右鍵 → ZotMax

選「AI 筆記（複製貼上，免 API key）」

② 複製提示詞

貼到 ChatGPT／Claude／Gemini 或學校的 AI

③ 把回答貼回來

按「儲存 AI 筆記並同步」

提示詞裡包含書目、摘要、你的劃線和整理過的全文，和 API 送出的完全一樣。要注意：全文會送到你選的網站，含病人資料或未發表資料要先確認規定，必要時去識別化；免費方案的內容可能被拿去訓練。

老師最常問

Q&A

要付費嗎？

外掛免費。AI 可以用網頁版（不另外付費）或 OpenRouter 免費模型；用自己的 API key 才依用量計費。

文獻會被送給 AI 嗎？

只有打開 AI 功能時才會送；自動同步不呼叫 AI。病人資料不要放進 AI。

更新後筆記還是舊樣子？

下次同步才會換版面；先對文獻「同步但不呼叫 AI」一次。

可以在 iPad 看嗎？

可以。筆記在電腦產生，用 Obsidian Sync、iCloud 或 Notion app 在平板上看。

金鑰和 Notion token 都存在 Zotero 的密碼管理員，不寫進設定檔。有問題可以用外掛裡的「回報問題」，或到 GitHub 開 Issue。
