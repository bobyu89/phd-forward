A · 它是什麼

不只「告訴你怎麼寫」，而是「幫你跑完」

一般聊天型 AI

  • 給你一段程式碼
  • 你自己複製、貼到 R / Python / SPSS 語法
  • 出錯了，再貼錯誤訊息回去問

Codex

  • 直接讀你資料夾裡的檔案
  • 自己寫程式、自己執行、自己除錯
  • 把表格、圖、程式檔留在資料夾裡

Codex 是 OpenAI 的程式 AI，用 ChatGPT 帳號登入；有桌面 App、網頁版、終端機版本。今天示範 Windows 桌面 App 的「工作」模式。

用一句話講差別：聊天型 AI 是「告訴你」，Codex 是「幫你做」。對不會寫程式的老師來說，最大的改變是不用自己處理環境和錯誤訊息。但也正因為它會自己動手，後面要講的資料安全和備份就更重要。
01
安裝與登入INSTALL · SIGN IN

① 搜尋 Codex

認明 OpenAI 官方網站（openai.com 或 chatgpt.com）

② 下載 Windows 版

chatgpt.com/codex 頁面上的「下載 Windows 版」

③ 用 ChatGPT 帳號登入

可以直接用 Google 帳號。免費方案可試用，用量較少；各方案上限以官網為準

現場可以請大家拿出筆電一起下載。提醒：搜尋結果可能出現非官方的下載站，只從 openai.com 或 chatgpt.com 下載。已經有 ChatGPT 帳號的人直接登入即可。
02
開一個專案PROJECT = YOUR DESK

切到「工作」→ 新增專案

專案就是 Codex 的工作桌：指定一個資料夾，把要分析的檔案放進去

它會問：要信任這個資料夾嗎？

信任後，它可以讀取、編輯、執行這個資料夾裡的檔案

!建議：每個分析開一個專用資料夾，裡面只放去識別化資料，不要直接指定整個「文件」或「下載」資料夾
「信任資料夾」是整個流程最重要的一個按鈕。它決定 Codex 能碰到哪些檔案。示範時我們用的是一個只放模擬資料的專用資料夾。

風險

怎麼做

先備份原始檔；點輸入框旁的權限按鈕，可查看或改用較保守的設定

最被低估的好處

程式留在資料夾裡，可以重跑、可以被檢查

survey_simulated.csv原始資料（它沒有改動）
analysis_survey.py分析程式：拿給統計老師看、之後資料更新直接重跑

這點對研究生特別重要：分析可以被重現。口試或審稿時被問「怎麼算的」，可以把程式交出去。

接下來可以這樣問

先檢查資料：列出每個變項的缺漏值、可能的輸入錯誤和極端值，不要修改原始檔。
比較四個年級的學習投入是否不同，先檢查前提假設，告訴我該用 ANOVA 還是無母數檢定，以及理由。
把描述統計和相關結果整理成 APA 第七版格式的表格。
用白話解釋你寫的每一段程式在做什麼，讓不會寫程式的人也看得懂。
第一條「不要修改原始檔」可以養成習慣，每次都加。第二條示範怎麼讓它先檢查假設、再選方法，但方法最後要由我們判斷。第四條很適合老師們，用來理解它到底做了什麼。
D · 方向盤在你手上

用 Codex 跑分析，記住三件事

01

去識別化

只放去識別化的資料；病人資料、未公開數據不進資料夾。依 IRB 與學校規定

02

自己判斷

統計方法由你決定，結果請指導老師或統計人員確認

03

先備份

它能修改檔案；原始檔先留一份，或要求它「不要修改原始檔」

三件事對應三種風險：隱私、統計錯誤、檔案損毀。第一點請特別強調：雲端 AI 處理的資料會送到服務商，臨床資料一律要先去識別化，並遵守 IRB 計畫書與機構規定。
老師最常問

Q&A

不會寫程式也能用嗎？

可以。用中文描述要做的分析即可；要它「用白話解釋每一步」，就能看懂它做了什麼。

結果可以直接放進論文嗎？

不建議直接放。方法與數字要自己核對、請統計人員確認，並依期刊規定揭露 AI 的使用。

資料會不會外流？

資料會送到 OpenAI 的服務處理。只放去識別化資料，並先確認帳號的資料使用設定與學校規範。

要付費嗎？

免費方案可以試用，但用量較少；常用的話再考慮付費方案。價格與上限以官網為準。

價格與方案常常變動，現場不要報數字，請大家以官網為準。關於資料：不同帳號類型（個人、教育、企業）的資料使用政策不同，要用在研究上前先查清楚。
